•開始前：兩個容易搞混的名詞

  • 連接器間距（族參數建議命名「本體總長度」）：伸縮節兩端連接器之間的距離。這是族的長度公式要用的基準數字。
  • 套接長度：接頭插入本體的長度，只影響外觀怎麼分段，不影響總長度怎麼算。
  • 允許位移量：型錄上「熱脹冷縮可以吸收多少」的數字（例如 ±25 mm），只是標示用途，不要拿來算族的長度，也不等於連接器間距。
為什麼要分清楚 型錄上這兩個數字通常分開列。如果把允許位移量當成連接器間距去建模，做出來的族長度會是錯的。

1準備族或範本

  1. 打開 Revit 2027。
  2. 檢查公司有沒有現成的「電纜槽聯結配件」族（.rfa）。有的話：檔案 → 開啟找到那個檔案，檔案 → 另存新檔存成新檔名（例如 CTF_電纜槽伸縮節_梯式.rfa），接著跳到步驟 2。
  3. 沒有現成族：檔案 → 新建 → 族，選電纜槽配件的公制範本（檔名通常包含 Cable Tray Fitting 字樣；繁中版實際顯示名稱還沒實機確認，找不到時用這個英文關鍵字搜尋）。範本資料夾一般在 C:\ProgramData\Autodesk\RVT 2027\Family Templates\<語系資料夾>，實際路徑以「檔案 → 選項 → 檔案位置」顯示的為準。

完成後：畫面開啟一個空白的族編輯環境，標題列顯示副檔名 .rfa。

卡住時：資料夾內沒有任何範本檔案，代表 Revit 安裝不完整，需要修復或重新安裝。

2設定族類別與零件類型

  1. 建立 → 族類別和參數。
  2. 族類別選「電纜槽配件」（不是「電氣設施」，選錯的話這個族之後在專案裡會找不到）。
  3. 零件類型：線架是梯式就選 Ladder Union，槽式就選 Channel Union。清單裡沒有單獨叫「Union」的選項，不要選那個。
  4. 線架是網格式的話，目前沒有官方對應類型，先跟公司討論要歸類成哪一種，做出來後再用步驟 7 的連接測試確認會不會通。
  5. 按確定關閉視窗。

完成後：族類別視窗顯示「電纜槽配件」，零件類型顯示你剛選的 Union 類型。

卡住時：繁中介面上實際顯示的中文字樣還沒實機確認過，找不到一模一樣的字時，用英文 Ladder Union／Channel Union 對照著找。

⚠ 不要把伸縮節設成線架的預設接頭 這個設定是在「電纜槽類型」裡，設下去之後，那個類型底下每一個接頭都可能自動變成伸縮節。伸縮節請維持手動放置，不要設成預設。

3建立尺寸參數

  1. 建立 → 族類型，開啟參數管理視窗。
  2. 新增以下型式參數（類型都選「長度」）：標稱寬度、標稱高度、本體總長度、左套接長度、右套接長度。
  3. 新增一個公式參數中央可見段，公式欄只填等號右邊：本體總長度 - 左套接長度 - 右套接長度。只有型錄證明左右套接不重疊時才能用這條公式，有重疊的話要照型錄分段直接填數字，不能用這條公式硬算。
  4. 新增一個文字型式參數允許位移量，只用來顯示型錄上的數字（例如 ±25 mm），不要用在任何公式裡。
  5. 建立幾個型式，名稱建議對應廠商料號（例如 200、300、400），每個型式分別填入實際數字。沒有型錄之前，先填一組練習用數字，記得拿到型錄後要整批換掉，不要當成正式規格使用。
  6. 把安裝間隙設成「執行個體」參數（不是型式），因為每個現場的間隙可能不一樣。
  7. 按確定存檔。

完成後：族類型視窗的下拉清單看得到所有型式，切換型式時每個型式底下的數字都不一樣。

卡住時：「中央可見段」算出負數或紅字錯誤，通常是套接長度比本體總長度還長，回頭核對型錄數字有沒有打錯。

如果同一型號未來有多種長度規格，等拿到型錄數字後，用「新增型式」的方式各開一個對應的型式即可，不要用公式硬做出沒有產品依據的任意長度。

4畫參考平面與外形，設定尺寸控制

  1. 切到樓層平面視圖，建立 → 參考平面畫出前、中心、後三條線，前後兩條用尺寸標註加上 EQ（讓兩段距離自動相等，中心線保持置中），總寬度的標註關聯到「標稱寬度」參數。
  2. 切到立面或剖面視圖，畫上、下兩條參考平面，標註關聯到「標稱高度」參數。
  3. 切到能看到族長度方向的視圖，沿長度方向由左到右畫 5 條參考平面：左端連接面、左套接分界、中心、右套接分界、右端連接面。
  4. 左端連接面到右端連接面的標註關聯「本體總長度」；左端連接面到左套接分界關聯「左套接長度」；右端同樣的方式關聯「右套接長度」。
  5. 用擠出等工具畫出本體的實體幾何。每個實體面都用對齊（AL）貼齊對應的參考平面，貼齊後點一下鎖頭圖示鎖定。中央段幾何位在左套接分界與右套接分界之間，這兩端的面也要鎖到這兩條參考平面，不鎖的話改尺寸時中央段不會跟著變長變短。
  6. 不需要把每個面都重複互相鎖定，鎖到對應的參考平面就夠了；也不要把一個實體面直接鎖到另一個實體面，改用鎖參考平面，比較不容易出現「過度約束」的錯誤。

完成後：在族類型視窗切換不同型式，或改標稱寬度、標稱高度的數字，幾何和參考平面會跟著連動變化。

卡住時：出現「無法保持這些造型限制條件」的警告，通常是同一個面被鎖了兩次，或鎖到錯的參考平面，檢查剛剛新增的鎖頭位置。

5放置兩端連接器，設定寬、高及方向

  1. 到左端連接面所在的視圖，建立 → 電纜槽連接器，點在「左端連接面」這個面上放置（放在面上是官方建議的做法，比放在工作平面上穩定）。
  2. 選取剛放的連接器，在內容面板把寬度用小型等號按鈕關聯到「標稱寬度」參數，高度關聯到「標稱高度」參數（兩個都要綁，只綁一個的話切換型式會跑版）。
  3. 用旋轉或翻轉工具，確認連接器箭頭朝向族的外側（背對本體中心）。
  4. 到右端連接面重複步驟 1 到 3，右邊的連接器箭頭也要朝外，兩端箭頭方向要相反。
  5. 檢查連接器中心是不是剛好落在族的長度中心軸線上，偏移的話用「對齊」工具拉回去。
  6. 數一下確認族裡只有這兩個連接器，沒有放錯地方或忘記刪除的多餘連接器。

完成後：兩端各有一個連接器圖示，切換型式時，連接器會跟著寬高變化一起移動。

卡住時：連接器選不到「關聯參數」的等號按鈕，通常是寬高欄位被鎖成固定數字，先把欄位改回可以輸入公式的狀態再試一次。

6切換尺寸測試，存成 .rfa

  1. 建立 → 族類型，逐一點選每一個型式（200、300、400⋯），每點一個都看一下平面圖、立面圖有沒有跑版或跳出警告。
  2. 改「本體總長度」或套接長度的數字，確認兩端連接器位置正確移動，中央段也跟著變長變短。
  3. 切換視圖左下角的詳細程度（粗略／中等／精細），確認三種都顯示合理，不是空白或破圖。
  4. 只要跳出任何黃色或紅色警告，都要點開看內容，回到步驟 4 檢查鎖定關係，不要留著警告繼續往下做。
  5. 全部型式都測過、沒有警告之後，檔案 → 儲存，檔名維持步驟 1 定的名稱，附檔名 .rfa。

完成後：所有型式都切換測試過，沒有跳出警告視窗，檔案已存檔。

卡住時：只有某一個型式出問題，通常是那個型式的數字打錯（例如套接長度比本體總長度還長），回族類型視窗核對數字。

7載入專案並連接兩段線架

  1. 打開要使用的 Revit 專案檔。
  2. 插入 → 從資料庫載入 → 載入族，選步驟 6 存好的 .rfa 檔案。
  3. 展開專案瀏覽器 → 族，確認新載入的族出現在「電纜槽配件」底下，不是「電氣設施」底下。位置不對就回第 2 步重新設定族類別，再重新載入一次。
  4. 在平面或立面視圖，先確認要連接的兩段線架，寬度、高度、中心線、高程這幾個數字都一致（高程欄位名稱以屬性面板實際顯示的為準）。
  5. 上方頁籤系統 → 電氣 → 電纜槽配件，在類型選取器選你剛做的伸縮節型式。
  6. 滑鼠點第一段線架要接的那個端點，放置伸縮節。
  7. 放置後，把第二段線架的端點拖曳過去，接到伸縮節另一端的連接器上。系統不會自動幫你補滿中間的缺口，一定要手動拖過去對齊。
  8. 如果產品分固定端跟活動端，安裝方向要照廠商圖面，不能兩邊隨便接。建議把伸縮節旋轉 180° 再接一次，確認兩個方向都符合預期。

完成後：兩段線架中間多了一段伸縮節，外觀看起來是連續的。

卡住時：伸縮節吸附不上線架端點，回步驟 5 檢查連接器的寬高有沒有關聯參數、方向是不是朝外。

補充：Revit 2027 的族庫預設位置是 %ALLUSERSPROFILE%\Autodesk\RVT 2027\Libraries，這是放完成族的族庫，跟步驟 1 的族範本資料夾不是同一個地方。

8檢查是否接通，建立配件明細表

  1. 上方頁籤分析 → 檢查系統 → 顯示斷開連接（這個路徑是依 2016 版文件寫的，繁中 2027 實際選單位置或字樣可能不同，找不到就用關鍵字「檢查系統」或「斷開」搜尋指令）。
  2. 勾選 Cable Tray and Conduit（電纜槽與導管）後執行檢查。
  3. 看伸縮節兩端的接合處有沒有出現斷開標記，沒有標記代表這兩個接點是通的。遠端故意留空的開口不算失敗。
  4. 額外可以把滑鼠停在線架和伸縮節上按 Tab 鍵，看反白範圍能不能連續選到整段。這個方法只能當輔助參考，不能取代步驟 1 到 3 的檢查結果——反白連續不代表系統一定判定為連通。
  5. 檢視 → 明細表 → 明細表/數量，類別選「電纜槽配件」（不是「電纜槽」，配件不會出現在電纜槽明細表裡）。
  6. 明細表欄位建議至少加入：族與型式、標稱寬度、標稱高度、本體總長度、安裝間隙、允許位移量、製造商、型號、數量、備註。要出現在明細表的自訂欄位（例如允許位移量），在步驟 3 建立參數時要選「共用參數」，不能選一般參數，否則明細表抓不到這個欄位。

完成後：檢查系統沒有在伸縮節接點出現斷開標記，明細表能列出剛才放置的伸縮節數量與規格。

卡住時：接點還是顯示斷開，先檢查專案端線架的高程、端點是不是真的對齊，再回族裡檢查連接器設定。一直接不上時，不要直接把族類別改成「一般模型」來繞過檢查——那樣會失去這個族原本該有的線架自動連接功能，問題要從連接器設定（步驟 5）去解決。

•疑難排解

狀況優先檢查處理方式
專案裡找不到族族類別回步驟 2 設為「電纜槽配件」，重新載入
放置時吸附不上連接器類型、方向回步驟 5：確認是電纜槽連接器、箭頭朝外、中心在軸線上
接上後尺寸不對連接器寬、高沒關聯參數回步驟 5：兩個連接器的寬、高都要綁到標稱參數
看起來接上，但有斷開標記端點是否真的重合、高程、截面先查專案端線架，再回族裡查連接器（步驟 8）
改尺寸後破圖過度約束、面直接鎖面回步驟 4，改由參考平面驅動，不要面鎖面
某些視圖看不到伸縮節可見性設定、詳細程度、視圖範圍、階段依序檢查可見性設定，不是調透明度
出現零或負長度錯誤套接長度大於本體長度回步驟 3，核對型錄數字和公式
每個接頭都變成伸縮節線架類型的預設接頭設定改回一般接續片（見步驟 2 警示）
怎麼接都顯示斷開直接把族類別改成一般模型逃避檢查不要這樣做，會失去自動連接功能；回頭排查連接器設定

•最低驗收清單

全部通過才能正式使用。勾選狀態只存在你這台電腦的瀏覽器。

•尚未確認事項

以下項目還沒有在 Revit 2027 繁體中文版實機操作確認過，主要集中在：介面上的中文顯示字樣（零件類型、「顯示斷開連接」選單位置與字樣、高程欄位名稱）、聯結配件夾在兩段線架中間時第二段線架會不會自動修剪、網格式線架該歸在哪一種零件類型、製造商與型號是否為「識別資料」內建參數。各步驟裡影響操作判斷的地方，已經在該步驟用文字提醒過一次，實際操作時仍要對照畫面調整。
